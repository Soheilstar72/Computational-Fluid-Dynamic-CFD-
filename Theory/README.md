# Computational Fluid Dynamic (CFD)

**CFD Reposity** is an open-source, educational CFD repository designed to take you from the very basics of computational fluid dynamics to advanced numerical solvers, all in one place.

The project combines:

- Clear theoretical notes (governing equations, discretization, stability, boundary conditions, etc.)
- Step-by-step example solutions (from 1D advection and diffusion to 2D/3D Navier–Stokes)
- Ready-to-run code and notebooks that illustrate each concept

The initial implementation uses Python and Jupyter notebooks to keep theory, explanation, and code together, but the repository is intentionally designed to be language-agnostic. In the future, the same examples and solvers can be reimplemented in other languages (e.g., C++, Fortran, Julia, MATLAB) while keeping a unified structure and documentation.

Whether you are learning CFD for the first time, preparing for interviews, or building a foundation for research, this repository aims to be a living **“CFD textbook + code lab”** that grows with you.
